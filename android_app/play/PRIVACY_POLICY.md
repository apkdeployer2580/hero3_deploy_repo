## 1. 수집하는 정보

이 앱은 **이름, 이메일, 전화번호, 주소, 위치, 연락처, 사진, 통화기록을 일절 수집하지
않습니다.** 계정 가입 절차가 없고, 로그인도 요구하지 않습니다.

앱이 다루는 정보는 다음 두 가지뿐입니다.

### (1) 기기 내부에만 저장되는 것

| 항목 | 설명 |
|---|---|
| 게임 세이브 | 캐릭터, 진행도, 인벤토리. 앱 전용 저장소에만 있습니다 |
| 앱 설정 | 화면 방향, 조작 방식, 버튼 배치, 서버 주소 |

앱을 삭제하면 함께 삭제되며, 기기 밖으로 나가지 않습니다. 안드로이드 자동 백업도
꺼져 있습니다(`allowBackup=false`).

### (2) 온라인 기능 사용 시 서버로 전송되는 것

앱의 온라인 기능(네트워크 창고, 캐릭터 복구, 상점)을 사용할 때만 해당합니다.
**오프라인으로만 플레이하면 아무것도 전송되지 않습니다.**

| 항목 | 설명 |
|---|---|
| 익명 계정 식별자 | 앱을 처음 실행할 때 **운영체제 난수 생성기로 만든 16바이트 무작위 값**입니다. 기기 식별자(IMEI, 광고 ID, MAC 주소 등)에서 만들어지지 않으며, 이 값으로는 어떤 개인도 특정할 수 없습니다. 앱을 삭제하면 사라집니다 |
| 게임 데이터 | 창고에 맡긴 아이템, 게임 내 재화 잔액, 캐릭터 복구용 백업 데이터 |

이 식별자는 **여러 사용자의 창고와 저장 데이터를 서로 구분하기 위한 용도로만** 쓰입니다.

## 2. 수집하지 않는 것

* **광고 없음** — 광고 SDK 가 포함되어 있지 않습니다
* **분석/추적 없음** — 애널리틱스, 사용 통계, 크래시 리포팅 SDK 가 없습니다
* **제3자 공유 없음** — 어떤 정보도 판매하거나 제3자에게 제공하지 않습니다
* **광고 식별자(AAID) 미사용**

## 3. 전송 구간 보안

서버와의 통신은 **TLS 로 암호화**됩니다.

## 4. 보관 기간

서버의 게임 데이터는 해당 계정 식별자로 접속이 없는 상태가 오래 지속되면 정리될 수
있습니다. 사용자가 삭제를 요청하면 즉시 삭제합니다.

## 5. 데이터 삭제

* **기기 내 데이터**: 앱을 삭제하면 세이브·설정·계정 식별자가 모두 지워집니다
* **서버 데이터**: 앱의 **설정 → ACCOUNT CODE** 에서 32자리 계정 코드를 확인한 뒤,
  아래 연락처로 그 코드를 보내주시면 해당 데이터를 삭제합니다

  삭제 요청: `<이메일 주소를 여기에>`
  삭제 요청 페이지: `<웹 URL 을 여기에>`

⚠ 계정 식별자는 기기에만 존재하므로, **앱을 먼저 삭제하면 서버 데이터를 지목할 수단이
사라집니다.** 서버 데이터 삭제를 원하시면 앱을 지우기 전에 계정 코드를 확인해 주세요.
