# Play Console 제출물 — 초안

이 폴더의 자산과 함께 Play Console 에 그대로 붙여 넣을 수 있게 정리한 것.
**이름/이메일/URL 처럼 내가 알 수 없는 값은 `<...>` 로 비워 뒀다.**

| 파일 | 용도 |
|---|---|
| `icon_512.png` | 앱 아이콘 (512×512, 필수) |
| `feature_1024x500.png` | 그래픽 이미지 (1024×500, 필수) |
| `PRIVACY_POLICY.md` | 개인정보처리방침 — **웹 URL 로 올려야** Console 에 넣을 수 있다 |
| 이 파일 | 스토어 등록정보 문구 + 데이터 보안 양식 답안 |

두 그래픽은 `tools/gen_play_assets.py` 가 원작 타이틀 아트에서 생성한다(런처 아이콘과
같은 소스·같은 헬퍼). 다시 만들려면 `python android_app/tools/gen_play_assets.py`.

## 1. 앱 이름 (30자 이내)

```
영웅서기3
```

> ⚠ Play 는 등록정보의 앱 이름과 실제 앱 라벨이 다르면 반려할 수 있다. 현재 앱 라벨도
> `영웅서기3` 이므로 일치한다(`res/values/strings.xml`).

## 2. 간단한 설명 (80자 이내)

```
피처폰 시절의 영웅서기3를, 요즘 폰에 맞는 조작으로 다시.
```
(38자)

## 3. 자세한 설명 (4000자 이내)

```
피처폰(WIPI) 시절의 RPG '영웅서기3 - 대지의 성흔'을 요즘 안드로이드 기기에서
플레이할 수 있게 만든 개인 프로젝트입니다.

원작을 그대로 구동하되, 조작과 화면은 지금 기기에 맞게 다시 만들었습니다.

■ 가로 전체화면
작은 세로 화면에 고정돼 있던 원작을 기기 비율에 맞춰 가로로 채웁니다.
확대해서 늘린 것이 아니라 실제로 더 넓게 그려집니다.

■ 손가락에 맞춘 조작
- 화면 아무 곳에서나 시작되는 플로팅 조이스틱
- OK 버튼을 둘러싸는 원형 스킬/아이템 버튼
- 버튼마다 위치와 크기를 직접 조절 (설정 → LAYOUT EDIT)
- 왼손잡이용 좌우 반전 한 번에

■ 다시 만든 HUD
- HP / SP / 경험치 게이지와 레벨을 화면 좌상단에
- 퀵슬롯 5칸을 실제 아이콘으로 표시
- 우상단 미니맵에 현재 위치 표시

■ 그 외
- 자동 루팅 기본 적용
- 세로/가로, 조이스틱/D-패드 전환

원작 게임 데이터가 함께 들어 있어 별도 파일 준비 없이 바로 실행됩니다.
```

## 4. 스크린샷 (필수: 휴대전화용 2장 이상, 최대 8장)

**아직 없다.** 기기에 최신 빌드를 설치한 뒤 직접 찍어야 한다 — 저장소에 있는
`d:\tmp\wie_saves\dt_*.png` 는 미니맵/에디터 변경 **이전** 빌드라 지금 앱과 다르다.

규격: PNG/JPEG, 최소 320px, 최대 3840px, 가로세로비 16:9 권장(가로 앱이므로 가로 방향).
2340×1080 기기 스크린샷이면 그대로 통과한다.

찍는 법:
```powershell
$Adb = 'D:\tmp\platform-tools\adb.exe'
$env:ANDROID_SERIAL = '<S25_SERIAL>'
& $Adb exec-out screencap -p > d:\tmp\wie_app\android_app\play\shot_01.png
```

찍을 장면 추천 (기능이 드러나는 순서):
1. 필드 플레이 — 조이스틱 + 원형 스킬 버튼 + 게이지 + 미니맵이 한 화면에
2. 미니맵이 잘 보이는 실내 (위치 점 포함)
3. 레이아웃 에디터 (설정 → LAYOUT EDIT) — "버튼을 직접 배치" 가 한눈에
4. 인벤토리/스킬 메뉴
5. 타이틀 화면

## 5. 데이터 보안(Data safety) 양식 답안

코드 기준으로 정확히 답한 것(`config.rs::read_or_create_account_id`, `network.rs`).

| 질문 | 답 | 근거 |
|---|---|---|
| 데이터를 수집/공유하나요? | **예** (온라인 기능 사용 시) | 계정 식별자 + 게임 데이터가 사설 서버로 감 |
| 수집 항목 | **앱 활동 → 기타 사용자 생성 콘텐츠**(창고 아이템·재화·캐릭터 백업)<br>**식별자 → 사용자 ID**(16바이트 난수) | |
| 개인정보(이름/이메일/전화/주소) | **아니요** | 수집 코드 자체가 없음 |
| 위치 / 연락처 / 사진 / 파일 | **아니요** | 해당 권한 자체가 없음 (`INTERNET`, `VIBRATE` 뿐) |
| 광고 ID(AAID) | **아니요** | 사용 안 함 |
| 제3자와 공유 | **아니요** | 운영자 본인의 서버로만 감 |
| 수집 목적 | **앱 기능** (계정 관리 / 게임 데이터 동기화) | |
| 수집이 선택사항인가 | **예** — 오프라인 플레이 시 전송 없음 | |
| 전송 중 암호화 | **예** | TLS. ★ 아래 경고 참조 |
| 삭제 요청 가능 | **예** | 개인정보처리방침의 삭제 절차 |

> ★★ **릴리스 빌드는 반드시 `tls://` 엔드포인트로 구워야 한다.**
> `HERO3_SERVER_HOST` 를 안 주면 `127.0.0.1`(평문) 로 폴백하고, 그러면 위 "전송 중
> 암호화 = 예" 가 **거짓 신고**가 된다. 빌드 스크립트가 이 경우 경고를 찍는다.
> ```powershell
> $env:HERO3_SERVER_HOST = 'tls://<서버주소>'
> $env:HERO3_SERVER_PORT = '8091'
> $env:HERO3_SERVER_PIN  = '<자체서명이면 SHA-256 지문>'
> .\build_android.ps1 -Release
> ```

## 6. 콘텐츠 등급 설문

원작 기준으로 답하면 된다. 판타지 RPG 전투(피 묘사 없음), 도박·성적 콘텐츠·약물 없음,
사용자 간 대화 기능 없음(창고/상점은 서버-클라 단방향), 위치 공유 없음, 앱 내 구매 없음.
→ 대체로 전체이용가 / PEGI 7 수준으로 나온다.
